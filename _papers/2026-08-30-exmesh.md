> **阅读依据**：本文笔记基于 CVPR 2026 camera-ready 论文、补充材料、官方项目页和截至 2026-08-30 可访问的官方代码仓库。论文实验主要覆盖 DTU 与 NeRF-synthetic 的物体级重建。文中结果来自论文原表；代码说明与论文存在初始化方式和耗时口径上的细微差异，已在相应位置标出。

## 背景与动机

- **隐式表面方法**：NeuS、VolSDF、Neuralangelo 等先学习 SDF/密度场，再通过 Marching Cubes 提取网格。它们通常几何精度较高，但训练慢，离散化可能损失薄结构与锐利边缘。
- **Gaussian-based 方法**：2DGS、PGSR、GOF、QGS 等优化显式 primitive，训练和渲染更快，但 Gaussian 并不是可直接编辑的 manifold mesh，最终仍需要 TSDF、Poisson 或 level-set extraction。
- **mesh-driven 方法**：Nvdiffrec、FlexiCubes、IMLS-Splatting 和 GeoSVR 在训练环中引入网格，却通常优化 SDF grid、point cloud 或 voxel 等中间载体，而不是直接把最终三角网格作为核心变量。
- **直接网格优化的困难**：固定拓扑无法从粗网格长出局部细节；统一 subdivision 又会让平坦区域产生大量冗余面。顶点移动还可能生成细长、翻折或不可见的退化三角形。
- **纹理与拓扑的冲突**：若颜色直接绑定到 vertex/face，为表达高频纹理必须增加几何密度；若使用独立 UV map，动态 split/merge 又会破坏 UV 索引、岛和 seam。

作者的核心判断是：高质量显式网格重建必须同时解决“哪里增加/删除几何自由度”和“拓扑变化后怎样保持可编辑纹理”两个问题。

**核心研究问题：能否直接优化显式网格，在训练中离散地改变拓扑，同时持续维护 UV，使最终结果兼顾几何精度、速度和较少面数？**

## 核心问题

1. **自适应细化**：怎样只在优化困难、曲率较大的区域增加面，而不做全局均匀细分？
2. **拓扑完整性**：怎样清除优化中产生的不可见面、冗余面和退化面，并避免 edge collapse 破坏局部连接？
3. **动态 UV 一致性**：新增或删除顶点后，怎样更新 UV index，并正确保留跨 UV island 的 seam？
4. **几何—纹理解耦**：怎样让纹理分辨率不再依赖面数，同时仍输出标准、可编辑的 UV texture？

## 方法详解

### 整体框架

ExMesh 的输入是多视图图像 $\{I\}$、相机参数、mask、单目深度先验和一个初始粗网格 $\mathcal{M}_{init}$。训练流程为：

1. 使用 nvdiffrast 将当前 mesh 和 UV texture 从采样相机渲染为图像、深度与 silhouette。
2. 图像损失的梯度分别更新网格顶点位置 $\mathbf V$ 和独立 UV texture $\mathbf T$。
3. 周期性统计顶点梯度、局部曲率、face 可见贡献和退化程度。
4. 对高价值区域执行 vertex split，增加局部几何容量；对不可见或退化区域执行 vertex merge，恢复简洁拓扑。
5. 每次拓扑更新同步修改 UV index；训练过程中还会定期重新 unwrap/pack UV map。
6. 最后冻结拓扑，只做连续几何与纹理 refinement，直接输出带 UV 的三角网格。

训练共 8K iterations：前 1K warm-up；1K–7K 每 500 iterations 执行一次 split/merge、每 2000 iterations 重建 UV；最后 1K 冻结拓扑。

### 关键设计一：梯度—曲率引导的 Adaptive Vertex Splitting

#### 候选 face 评分

作者首先为每个顶点维护位置梯度模长的指数移动平均（EMA）：

$$
\mathcal G_v^{(t)}=(1-\beta_g)\mathcal G_v^{(t-1)}+\beta_g\left\|\nabla_{\mathbf V}^{(t)}\right\|.
$$

较大的 $\mathcal G_v$ 表示当前区域持续收到较强几何修正信号，现有拓扑可能没有足够自由度拟合观测。

对于 face $\mathcal F$，再用它与相邻 face 法线的平均夹角估计局部曲率：

$$
\mathcal K_f=\frac{1}{N_{adj}}\sum_{\mathcal F_{adj}}
\arccos(\mathbf n_f\cdot\mathbf n_{adj}).
$$

最终 sampling score 为：

$$
S_f=\alpha\mathcal G_f+\beta\mathcal K_f,
$$

其中 $\mathcal G_f$ 是三个顶点 EMA gradient 的平均。候选只取面积排名前 50% 的 face，避免已经很细的小面继续无限分裂。

梯度回答“哪里还没有拟合好”，曲率回答“哪里本来就需要更复杂几何”。两者结合比单纯按面积 uniform refinement 更具有任务适应性。

#### Split 操作

对被选 face，作者根据边长与顶点 degree 的比值 $S_e=l_e/d_e$ 选取需要 split 的 edge：长边更值得细分，高 degree 顶点附近则受到抑制。

- 若是内部 edge，相邻两个三角形的对顶点分别投影到该 edge，新顶点位于两个投影点的平均位置；两个原 face 被替换为四个 face。
- 若是 boundary edge，新顶点放在 edge 中点，一个原 face 被替换为两个 face。
- 若新顶点在 edge 上的相对位置不在 $[0.25,0.75]$，或相邻 face 已被本轮其他操作修改，则跳过，降低细长三角形和并发拓扑冲突风险。

这个操作不是传统的“最长边取中点”细分：内部 edge 的新顶点位置由两侧局部形状决定，希望初始位置更贴合曲面趋势。

### 关键设计二：可见性—退化度引导的 Adaptive Vertex Merging

Split 增加表达能力，merge 则负责删除没有贡献或已经变坏的局部结构。作者采用两个判断信号：

1. **Render contribution count** $\mathcal C_{render}(\mathcal F)$：face 在训练 rasterization 中从未贡献像素，即 $\mathcal C_{render}=0$，可能是内部面、完全遮挡面或无用冗余。
2. **Degeneracy**：

$$
\mathcal D_f=\frac{\operatorname{Area}(\mathcal F)}{l_{max}^2(\mathcal F)}.
$$

面积相对于最长边平方越小，三角形越细长、越接近退化。实验阈值 $\tau_{degen}=0.05$。

Merge 候选只来自面积排名后 50% 的 face，并需满足不可见或退化条件。对于 boundary face，优先 collapse boundary edge 以保持边界；内部 face 则选择较小 score 的 edge。两个端点中 degree 较低的顶点被合并到 degree 较高的顶点，然后删除同时含两端点的 face，并把其余邻面重新连接到保留顶点。

这里的目标不只是减少面数，更重要的是在可微顶点移动不断扰乱局部网格时，周期性恢复可用拓扑。

### 关键设计三：实时 UV 维护

几何由 mesh vertex position $\mathbf V$ 表示，纹理由固定分辨率 UV map $\mathbf T$ 表示。UV coordinate $\mathbf u$ 连接 face corner 与 texture。这样纹理容量由 texture resolution 决定，不需要通过增加 vertex/face 数量来提高颜色分辨率。

难点发生在 split 后的新顶点 $v_s$：

- boundary edge 上直接线性插值得到新 UV；
- 内部 edge 的两个邻面可能处于同一 UV island，也可能隔着 seam。作者分别在两个 face 的 UV edge 上插值得到 $u_s^{(1)}$ 和 $u_s^{(2)}$；
- 若两者距离小于 $\tau_{uv}$，取平均并共享一个 UV；否则保留两个独立 UV coordinate，维持 texture seam；
- merge 删除顶点后，移除不再被任何 face 引用的 UV，并重排 index。

此外，训练每 2000 iterations 使用 LSCM/ABF++ 重新 unwrap 和 pack UV。实时插值维持局部连续性，周期性全局重建则处理多轮拓扑变化后 UV island 碎裂与空间利用率下降。

### 关键设计四：几何与纹理解耦优化

顶点位置和 2560×2560 UV texture 接收同一可微渲染损失的梯度，但作为独立参数优化：

- vertex 只需要承担几何形状；
- texel 承担高频颜色；
- 输出 texture 是标准 UV map，可直接编辑，不像 coordinate MLP 还需要训练后 baking。

这一设计是 ExMesh 能同时保持约 200K faces 与较高 rendering quality 的关键，而不仅是 split/merge 本身。

### 损失函数

总损失为：

$$
\mathcal L=\lambda_{rgb}\mathcal L_{rgb}+\lambda_d\mathcal L_d+
\lambda_m\mathcal L_m+\lambda_s\mathcal L_s+\lambda_b\mathcal L_b.
$$

- $\mathcal L_{rgb}$：L1 与 D-SSIM 的组合，$\lambda_{dssim}=0.2$。
- $\mathcal L_d$：rendered depth 与 Depth Anything 3 reference depth 的 Pearson correlation loss；它约束相对深度结构，而不要求单目深度具有正确绝对尺度。
- $\mathcal L_m$：rendered alpha 与 object mask 的 BCE silhouette loss。
- $\mathcal L_s$：Laplacian smoothing，压制局部高频几何噪声。
- $\mathcal L_b$：相邻顶点 deformation offset 的平滑正则，抑制突然拉伸与折叠。

论文默认 $\lambda_{rgb}=1$、$\lambda_d=0.01$、$\lambda_m=0.005$、$\lambda_s=\lambda_b=1000$。较大的平滑正则权重说明直接 mesh optimization 对局部拓扑稳定性仍非常敏感。

### 初始化与“直接重建”的实际边界

论文实验先训练 2DGS 7K iterations（约 2 分钟），再通过 $256^3$ TSDF 提取粗网格，之后运行 ExMesh。官方 README 当前推荐用 PGSR 5K iterations 加 TSDF 作为更稳定的初始化。

因此，ExMesh **直接优化和输出的是最终 mesh**，训练主体不需要再从 SDF/Gaussian 做最终 meshing；但完整输入到输出 pipeline 仍依赖 Gaussian-based reconstruction 和 TSDF 得到初始粗网格。论文“绕过 intermediate representation/post-processing”的表述需要限定在 ExMesh refinement 阶段，而不能理解为从原始多视图图像完全摆脱中间表示。

作者也展示了从随机颜色、约 1000 faces 的 sphere 开始仍可重建，但需要更多 iterations，最终几何精度稍差，而且只提供了定性图，没有主表级量化。

## 实验关键数据

### 实验设置

- **DTU**：15 个真实物体场景，每个 49 或 69 张图；图像从 1600×1200 下采样至 800×600。几何指标为 Chamfer Distance（CD，越低越好）。
- **NeRF-synthetic**：8 个合成物体场景，100 张训练图、200 张测试图，分辨率 800×800。报告 CD、PSNR、SSIM 和 LPIPS。
- 所有实验在单张 NVIDIA RTX 3090 上完成。
- ExMesh 和多种 baseline 使用 object mask；ExMesh 还使用 Depth Anything 3 单目深度先验。

### DTU：几何质量、时间和面数

| 方法 | 类型 | 平均 CD ↓ | 总时间 ↓ | Faces ↓ |
| --- | --- | ---: | ---: | ---: |
| Neuralangelo | NeRF/SDF | 0.62 | >12 h | 1.98M |
| 2DGS | GS + TSDF | 0.76 | **11 min** | 260K |
| PGSR | GS + TSDF | **0.52** | 30 min | 1.05M |
| QGS | GS-based | 0.54 | 48 min | 252K |
| GeoSVR | mesh-driven/voxel | **0.47** | 49 min | 1.12M |
| **ExMesh** | direct mesh refinement | **0.58** | **13 min** | **196K** |

来源为正文 Table 1。补充材料效率表将 ExMesh 记为 15 分钟、4.5 GB；正文主表为 13 分钟。两者可能是统计口径或运行差异，论文没有解释。

ExMesh 不是 DTU 几何精度最优：比 GeoSVR 差 0.11 CD，比 PGSR 差 0.06，也略差于 QGS。但它使用的 faces 只有 GeoSVR 的约 **17.5%**、PGSR 的约 **18.7%**，时间约为 GeoSVR 的 **26.5%**、PGSR 的 **43.3%**。因此最有说服力的结论是 Pareto-style trade-off，而不是新的绝对 SOTA。

与同样快速的 2DGS 相比，ExMesh 多约 2 分钟，但 CD 从 0.76 降至 0.58，faces 从 260K 降至 196K。这是对“拓扑 refinement 有实际价值”比较直观的证据，不过 ExMesh 本身又以 2DGS/TSDF mesh 初始化，两者并非完全独立 pipeline。

### NeRF-synthetic：复杂拓扑几何

| 方法 | 平均 CD ↓ | 时间 ↓ | Faces ↓ |
| --- | ---: | ---: | ---: |
| Neuralangelo | **0.60** | >12 h | 8.387M |
| NeuS | 0.69 | >12 h | 未报告 |
| IMLS-Splat | 0.73 | 15 min | 578K |
| Nvdiffrec | 0.94 | >1 h | **81K** |
| **ExMesh** | **0.64** | **13 min** | 216K |

ExMesh 平均 CD 排名第二，仅次于 Neuralangelo，同时训练时间从 12 小时以上缩短到约 13 分钟。它比 IMLS-Splat 将 CD 改善 0.09，并减少约 62.6% faces。但 ship 场景 CD 为 1.24，明显弱于 Neuralangelo 的 0.34 和 GOF 的 0.91，说明平均优势并不覆盖所有复杂拓扑或反射条件。

### NeRF-synthetic：新视角渲染

| 方法 | 表示 | PSNR ↑ | SSIM ↑ | LPIPS ↓ |
| --- | --- | ---: | ---: | ---: |
| 3DGS | Gaussian | 33.32 | 0.969 | **0.030** |
| TriSplat | Triangle soup | **33.87** | **0.970** | **0.030** |
| Nvdiffrec | Mesh | 26.87 | 0.930 | 0.090 |
| FlexiCubes | Mesh | 27.50 | 0.930 | 0.080 |
| IMLS-Splat | Mesh | 28.38 | 0.950 | 0.060 |
| **ExMesh** | Mesh + UV | **29.32** | **0.958** | **0.051** |

ExMesh 在 mesh-driven 方法中三项都最好，PSNR 比 IMLS-Splat 高 0.94 dB；但仍比 3DGS 低 4.0 dB。作者将差距归因于 Gaussian/SH 更容易表达 view-dependent appearance。更严格地说，ExMesh 使用单张静态 UV texture，本身没有显式的方向相关 appearance model，因此这个差距是表示能力预期内的结果。

### Split/Merge 消融

| 设置 | CD ↓ | PSNR ↑ | Faces |
| --- | ---: | ---: | ---: |
| Only Split | 0.74 | 28.77 | 239K |
| Only Merge | 1.81 | 23.51 | 12K |
| Random Split | 0.77 | 28.30 | 184K |
| Random Merge | 1.34 | 26.27 | 192K |
| **完整方法** | **0.64** | **29.32** | 196K |

来源为正文 Table 4。

- Only Merge 只剩 12K faces，几何和渲染显著崩溃，证明粗 mesh 确实需要增加自由度。
- Only Split 可以恢复较多细节，但 faces 比完整方法多约 22%，且 CD 更差，说明 merge 不只是压缩，还在清理优化产生的坏拓扑。
- Random Split 与完整方法 face 数相近但 CD 差 0.13，支持 gradient/curvature criterion 和 split position 设计有用。
- Random Merge 的下降最大，说明 edge collapse 的位置选择比“是否进行 merge”本身更关键。

不过这个消融同时改变 candidate、edge 和操作位置，无法完全拆分 gradient、curvature、area filtering、degree score 各自贡献。论文也没有报告 split/merge 操作成功率、face 数随训练的完整曲线或 topology validity 统计。

### 纹理表示消融

| 纹理表示 | CD ↓ | PSNR ↑ | Faces |
| --- | ---: | ---: | ---: |
| Per-Vertex Color | 0.76 | 28.47 | 356K |
| Per-Face Color | 0.78 | 28.12 | 442K |
| Coordinate MLP | **0.64** | 28.87 | 198K |
| **UV Map** | **0.64** | **29.32** | **196K** |

来源为正文 Table 5。把颜色绑定到几何需要 356K–442K faces，仍比 UV map 的 PSNR 低 0.85–1.20 dB。Coordinate MLP 在几何和面数上接近，但 PSNR 低 0.45 dB，而且最终需要 texture baking；UV map 在训练中就保持标准可编辑纹理。

定性消融还显示，如果只在训练开始时生成一次 UV，后续拓扑变化会造成 island fragmentation、stretching 和低 packing efficiency，纹理变模糊。因此“拓扑操作时的局部 UV 更新”与“周期性全局 UV 重建”缺一不可。不过论文没有给这项消融的数值或 UV 重建耗时。

### 效率与规模

补充材料 Table 2 报告 ExMesh 在 DTU 上约 15 分钟、峰值 4.5 GB：

- memory 仅高于 PGSR/QGS 的 3.5 GB，显著低于 SuGaR/TriSplat 的 23 GB、IMLS-Splat 的 20 GB；
- 2DGS 仍更快，为 11 分钟、5 GB；
- face count 增加到约 100K 前几何精度明显改善，超过 200K 后收益趋于饱和，作者建议 150K–250K 作为折中区间。

主要规模瓶颈不是 rasterization，而是 CPU xatlas UV unwrapping。作者指出 faces 超过 200K 后 unwrap 明显变慢，这限制了 scene-level reconstruction。

### 超参数与损失消融

论文将 degeneracy threshold 和多个 loss weight 分别缩放到默认值的 0.5–2.0 倍，DTU CD 曲线整体稳定。补充材料的定性消融显示：去掉 Laplacian loss 会增加薄结构与边界的高频锯齿；去掉 bi-vertex offset loss 会出现局部拉伸、折叠和 deformation discontinuity。

但论文没有为 loss 消融提供定量表，也没有联合改变多个超参数。作者在 limitations 中仍承认需要手工调节多个 loss 和 topology threshold，因此“单参数局部稳定”不能等价为跨数据集无需调参。

### 关键发现

1. 在可微 mesh optimization 中交替进行自适应 split 和 merge，确实优于只增不减、只减不增或随机拓扑操作。
2. ExMesh 的核心优势是以约 200K faces 和十余分钟达到接近最佳方法的几何精度，而非拿到最低 CD。
3. 独立 UV map 明显降低了纹理对几何密度的依赖，并优于其他 mesh-driven 方法的 rendering quality。
4. 当前方法仍依赖粗网格、object mask 和单目深度先验，且动态 UV unwrapping 阻碍更大规模场景。
5. 显式 mesh 在标准可编辑资产方面有结构优势，但静态 UV texture 的 novel-view rendering 仍落后于带方向相关颜色的 Gaussian 表示。

## 亮点与洞察

### 论文亮点

- **连续优化与离散拓扑更新结合自然**：顶点位置/texture 用 gradient descent，mesh connectivity 用显式 split/merge，各自使用适合自身的数据结构与优化方式。
- **Split 与 merge 的判据具有可解释性**：gradient、curvature、visibility、degeneracy 分别对应拟合需求、几何复杂度、观测贡献和拓扑质量。
- **UV seam 处理细致**：新顶点在两个 UV island 上可以持有两个 UV coordinate，避免简单平均跨越 seam。
- **实验强调真实资产属性**：除了 CD，还报告 time、memory、faces 和 UV texture quality，更符合显式 mesh 的实际使用需求。
- **代码已公开**：仓库包含训练、renderer、scene、evaluation 脚本和依赖说明，而不只是 project page。

### 我的洞察

- **个人分析：这是 mesh-space 的 densification/pruning。** ExMesh 与 3DGS 的 density control 思路高度相似：gradient 较大的 primitive 被 densify，低贡献或坏 primitive 被 prune。差别是 mesh 有邻接和 manifold 约束，任何局部增删都必须同步维护 connectivity 与 UV。
- **个人分析：UV 维护可能比 split/merge 更具工程价值。** 单独的 adaptive remeshing 并非新问题；真正让它适合 multi-view reconstruction pipeline 的，是 topology change 后 texture 仍保持可训练、可输出、可编辑。
- **个人分析：评价 concise mesh 不能只看 face count。** 还应报告 non-manifold edges、self-intersections、skinny triangle ratio、connected components、UV overlap 和 seam length。论文主要依赖视觉结果，没有系统量化拓扑质量。
- **个人分析：结果体现明显 Pareto frontier。** GeoSVR 追求更低 CD，Nvdiffrec 追求更少 faces，Gaussian 方法追求更高 rendering quality；ExMesh 选择三者中间的工程平衡点。
- **个人分析：对 3DGS 表面重建的启发**：可以先利用 Gaussian 提供快速覆盖和深度先验，再在 mesh space 中用 visibility/gradient 驱动局部 topology adaptation，而不是依赖一次性 TSDF extraction 后固定拓扑。

## 局限与展望

### 作者承认的局限

- 多个 loss weight 与 topology threshold 仍需手工设置，可能依赖专家经验。
- xatlas 为 CPU 实现，faces 超过 200K 后 UV unwrapping 成为明显瓶颈。
- 自动超参数选择和 GPU-accelerated UV unwrapping 是主要后续方向。

### 独立分析

- **“end-to-end/direct”表述偏强**：主实验先用 2DGS/PGSR 和 TSDF 得到 coarse mesh，且依赖 DA3 depth 与 object mask。ExMesh refinement 本身直接优化 mesh，但完整系统仍是多阶段 pipeline。
- **数据范围较窄**：DTU 和 NeRF-synthetic 都是中心化、物体级、多视角较密集场景；没有展示室内、室外、无界或大尺度 scene reconstruction。
- **初始化依赖没有充分量化**：从 sphere 开始只有定性结果；没有比较 2DGS、PGSR、不同 mesh resolution、拓扑错误初始化对最终性能和时间的影响。
- **Mask/depth prior 的贡献不清楚**：主结果使用 object mask 和 DA3 depth，但没有分别消融它们。与不使用相同先验的 baseline 比较时，提升来源可能混合。
- **拓扑合法性缺乏指标**：merge 中的局部 relinking 并不自动保证全局 manifold、无 self-intersection 或一致 winding；论文没有报告这些统计。
- **UV 更新成本未拆分**：总时间很快，但没有单独报告 split/merge、xatlas unwrap、rasterization 和 texture optimization 的时间占比。
- **视角相关外观缺失**：单 UV texture 无法表达反射随视角变化；在 shiny/transparent object 上，photometric gradient 可能错误推动 geometry 来解释 appearance。
- **复现说明仍需打磨**：官方 README 的 clone 命令仍是 `YourUsername/ExMesh.git` 占位符，论文使用 2DGS 初始化，而 README 推荐 PGSR，复现者需要明确选择和统一口径。

### 建议的后续实验

1. 在相同初始化、mask 和 depth prior 下，对 2DGS/PGSR + fixed mesh refinement 与 adaptive topology 做严格配对。
2. 报告 manifold rate、connected components、self-intersections、最小角分布和 UV overlap 等 mesh quality 指标。
3. 将 split/merge candidate score 分别拆成 gradient-only、curvature-only、visibility-only 和 degeneracy-only 消融。
4. 在 Tanks and Temples、MipNeRF360 或室内房间上验证 scene-level scalability，并记录 UV unwrap 时间占比。
5. 为 UV texture 加入轻量 view-dependent residual，测试能否缩小相对 3DGS 的约 4 dB rendering gap，而不牺牲标准 mesh 资产格式。

## 与相关工作的对比

| 方法 | 核心优化表示 | 拓扑变化 | 纹理表示 | 最终 mesh 获得方式 |
| --- | --- | --- | --- | --- |
| 2DGS / PGSR | 2D Gaussian disks | Gaussian densification | SH/color | 训练后 TSDF fusion |
| Triangle Splatting | Unstructured triangle soup | 非标准 manifold topology | primitive color/feature | triangle primitive 本身 |
| Nvdiffrec | Tetrahedral SDF grid | 通过 DMTet extraction 改变 | Coordinate MLP，后 baking | differentiable marching tetrahedra |
| FlexiCubes | Voxel SDF grid | differentiable dual MC | mesh material/texture | differentiable isosurface extraction |
| IMLS-Splatting | Point cloud + sparse SDF | 由中间载体间接决定 | 与 carrier 关联 | IMLS meshing |
| **ExMesh** | **显式 triangle mesh vertex** | **离散 split/merge** | **训练中维护的独立 UV map** | **优化后的 mesh 直接输出** |

ExMesh 与这些方法最本质的区别，是 connectivity 本身在训练期间作为可修改的离散状态存在，而不是每次从连续场或点/体素载体重新提取。

## 启发与关联

- **对 mesh refinement**：可以把可微渲染 gradient 看作“哪里需要更多 topology capacity”的数据驱动误差估计，再用 curvature 防止完全由 appearance noise 决定细分。
- **对 3DGS surface reconstruction**：Gaussian/2DGS 可以作为快速 coarse initialization，但最终资产质量可在 mesh space 通过 topology cleanup 继续优化。
- **对移动端与实时资产**：200K faces 仍不算低模，但比百万级 mesh 更接近可用资产；后续可结合 QEM、LOD 或 task-aware simplification。
- **对纹理编辑**：与 neural texture 相比，训练中原生 UV map 更容易接入 DCC 软件、手工修补、材质编辑和游戏引擎。
- **假设**：若将 render contribution count 换成多视角可见性置信度，并将 split score 与真实几何 uncertainty 结合，可能减少 specular region 被错误细分的问题。

## 阅读结论

- **最值得记住的点**：ExMesh 把 mesh topology 当作训练中可周期更新的离散变量，并在每次变化时同步维护 UV，而不是把 mesh extraction 留到训练结束。
- **最需要怀疑的点**：它并未在完整 pipeline 中彻底摆脱 Gaussian/TSDF 初始化，也没有证明输出 mesh 在 manifold、self-intersection 和 UV validity 上系统优于 baseline。
- **最值得复现或继续验证的点**：在统一 PGSR/2DGS coarse mesh 上比较 fixed-topology refinement 与完整 split/merge，记录 CD、faces、坏三角形比例、UV unwrap 开销和 rendering quality 的共同变化。
