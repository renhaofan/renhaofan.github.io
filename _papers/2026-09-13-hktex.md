## 一句话总结

HKTex 不再把曲面摊平到二维 UV atlas，而是把外观表示成**直接生长在三角网格流形上的一组可学习各向异性热核**：核的形状由各向异性 Laplace–Beltrami 谱控制，位置以黎曼梯度沿表面更新，再用误差驱动的流形增密与双调和 KNN 做局部高效求值；它确实以较小序列化体积获得了很强的纹理拟合质量和无接缝表示，但目前用高昂的谱预计算、较慢的查询/渲染和严格网格前提换取了这一优势。

## 背景与动机

- **领域现状**：传统 mesh appearance 主要依赖 UV mapping，即把三维曲面参数化到二维平面并存储纹理图。其优点是硬件生态成熟、随机访问快、编辑工具完善。
- **UV 的结构性问题**：任意拓扑曲面通常无法无失真地摊平，因此会产生 seam、局部拉伸/压缩、纹素密度不均；atlas 空白区域浪费纹理空间，接缝处还需复制顶点并额外保存每顶点 UV 坐标。
- **已有替代路线**：坐标 MLP、InstantNGP/hash-grid、Intrinsic Neural Fields（INF）、vertex colour 与 point/Gaussian texture 可以减少部分 UV 依赖，但分别面临网络求值开销、拓扑/顶点采样绑定、原语数过多或仍在 ambient Euclidean space 中优化的问题。
- **3DGS 带来的启发与误区**：Gaussian primitive 具有局部、显式、可增密的优点；但普通 3D Gaussian 是欧氏空间中的刚性椭球，不能自然弯曲贴合任意曲面，位置优化还会把它拉离 mesh。作者因此不是把 Gaussian “贴”到表面，而是寻找其内蕴几何对应物。
- **作者切入点**：欧氏空间的 heat kernel 就是 Gaussian；在黎曼流形上，热核沿 geodesic 扩散，天然随曲面弯曲。因此可把“Gaussian texture”改写为“manifold heat-kernel texture”。

**核心研究问题：能否在完全不构造 UV 参数化的情况下，以可学习、局部、可增密的曲面内蕴原语表达高频纹理，并同时支持从既有纹理压缩和多视图可微逆渲染？**

## 核心问题

1. **离散谱与连续纹理的矛盾**：LBO eigenfunctions 只定义在 mesh vertices 上，但纹理必须能在任意 ray–surface intersection 连续求值，核中心也不应锁定到顶点。
2. **每个核具有不同各向异性**：若为每个核、每次迭代重新构造 anisotropic LBO（ALBO）并 eigendecompose，计算不可承受；但简单共享一套谱又无法学习方向和长宽比。
3. **全局支持导致复杂度与 ringing**：截断谱热核理论上遍布整张曲面，直接计算 $P$ 个查询点对 $S$ 个核是 $O(P S)$，远处还会出现 Gibbs-like spectral ringing。
4. **核位置和密度必须尊重流形**：欧氏梯度更新、clone/split 都可能离开曲面；需要把优化、动量、分裂方向和位移都重新定义到 mesh manifold 上。
5. **存储优势是否转化为系统优势**：要区分最终 kernel parameters 的序列化体积、每 mesh 的谱预计算缓存、预计算时间、训练/渲染延迟与部署条件，不能只看最终 KB。

给定 manifold mesh $\mathcal M=\{\mathbf X,\mathbf F\}$，HKTex 维护 $S$ 个 kernel：

$$
\mathcal K=\{\boldsymbol\kappa_s\}_{s=1}^{S},\qquad
\boldsymbol\kappa=(\boldsymbol p^\star,\theta,\eta,\tau,\varsigma,\mathbf c).
$$

其中 $\boldsymbol p^\star$ 是曲面上的 source position，$\theta$ 是扩散方向，$\eta$ 是 anisotropy，$\tau$ 控制空间尺度，$\varsigma$ 控制边界锐度，$\mathbf c$ 是 RGB residual colour。所有参数联合优化；位置用专门的 geodesic optimizer，其他参数用 Adam + projected gradient descent（PGD）约束范围。

### 1. 从 Gaussian 到曲面上的各向异性热核

设 ALBO 的前 $K$ 个 eigenpairs 为 $\{\lambda_k^{\eta,\theta},\varphi_k^{\eta,\theta}\}$。从 source $\boldsymbol p^\star$ 扩散时间 $t$ 后，在任意曲面点 $\boldsymbol p$ 的截断谱热核为（论文 Eq. 3）：

$$
h_t(\boldsymbol p,\boldsymbol p^\star\mid\theta,\eta)
=\sum_{k=1}^{K}e^{-t\lambda_k^{\eta,\theta}}
\varphi_k^{\eta,\theta}(\boldsymbol p)
\varphi_k^{\eta,\theta}(\boldsymbol p^\star)m^\star.
$$

- $e^{-t\lambda_k}$ 是 diffusion low-pass：高频 eigenmode 衰减更快；$t$ 越大，热扩散范围通常越广。
- $\theta,\eta$ 通过 ALBO 改变扩散的主方向和拉伸程度，使核成为会沿曲面弯曲的 geodesic ellipse。
- $m^\star$ 是 source mass。论文提出 KDE 估计，但实验最终统一设为 1，因为更快且精度未下降；其他可学习参数可吸收线性尺度差异。

热扩散守恒会让大核中心温度下降，不利于统一控制。作者以 source 自响应归一化（Eq. 4）：

$$
\bar h_t(\boldsymbol p\mid\boldsymbol p^\star,\theta,\eta)
=\frac{h_t(\boldsymbol p,\boldsymbol p^\star\mid\theta,\eta)}
{h_t(\boldsymbol p^\star,\boldsymbol p^\star\mid\theta,\eta)}.
$$

这样每个核中心均为 1，后续相同阈值在不同形状/尺度的核上具有更一致的含义。

### 2. 双调和衰减：同时抑制 ringing 并构造局部查询

只保留有限 eigenmodes 会让远处出现 spectral ringing。作者先用 isotropic LBO 定义 biharmonic distance：

$$
d_{\mathrm{BH}}(\boldsymbol p,\boldsymbol p^\star)^2
=\sum_{k=1}^{K}
\frac{\left(\varphi_k^{\mathrm{iso}}(\boldsymbol p)-
\varphi_k^{\mathrm{iso}}(\boldsymbol p^\star)\right)^2}
{(\lambda_k^{\mathrm{iso}})^2},
$$

再乘 Gaussian window（Eq. 5）：

$$
\tilde h_t=\bar h_t\cdot
\exp\left(-\frac{d_{\mathrm{BH}}^2}{2\sigma_{\mathrm{BH}}^2}\right).
$$

它有两个作用：

1. **数值上**把远距离 ringing 压到 filtering cutoff 以下；
2. **算法上**把核变成有效局部支持，使远处 kernel 可以安全跳过。

将每个点嵌入

$$
\mathbf z(\boldsymbol p)\approx b^{\boldsymbol p}
\left(\mathbf\Phi^{\mathrm{iso}}(\mathbf\Lambda^{\mathrm{iso}})^{-1}\right),
$$

则 embedding 中的 Euclidean distance 对应 biharmonic distance。作者用 GPU FAISS 为每个 target point 找 $K_s=50$ 个邻近 sources，把核心复杂度从 $O(P S)$ 降至 $O(PK_s)$。注意这是**截断谱 embedding 下的近似连续距离**，不是精确 geodesic distance。

### 3. 独立控制尺度和边界锐度

作者固定 diffusion time $t$，而不是让每个核直接学习 $t$；再对 $\tilde h_t\in[0,1]$ 使用 rescaled sigmoid（Eq. 6）：

$$
\alpha(\boldsymbol p)
=\frac{\xi(\tilde h_t(\boldsymbol p))-\xi(0)}{\xi(1)-\xi(0)},
\qquad
\xi(x)=\sigma\left(\varsigma(x-\tau)\right).
$$

- $\tau$ 是 level-set threshold：越接近 1，只保留越靠近峰值的区域，核越小。
- $\varsigma$ 控制 sigmoid slope：值越大，边界越接近 crisp geodesic ellipse；值较小时保留柔和衰减。
- 重新缩放确保输出仍落在 $[0,1]$。

该设计把 diffusion 的底层几何形状与可学习 footprint 分离，也让 split 时可用 $1-\tau$ 近似 kernel radius。

### 4. Partition of Unity 颜色合成

对查询点 $\boldsymbol p$，取贡献最大的 $K_c$ 个 kernels（UV fitting 为 30，multi-view 为 20），以归一化权重混合颜色，并叠加全局 base colour（Eq. 7）：

$$
C(\boldsymbol p)=\mathbf c_{\mathrm{base}}+
\frac{\sum_{s\in\mathcal K(\boldsymbol p)}\alpha_s(\boldsymbol p)\mathbf c_s}
{\sum_{s\in\mathcal K(\boldsymbol p)}\alpha_s(\boldsymbol p)}.
$$

$\mathbf c_s\in[-1,1]^3$ 是可正可负的 residual，因此少量 kernels 可以在平均色上表达高频加性或减性细节；空白区域回退到 $\mathbf c_{\mathrm{base}}\in[0,1]^3$。与 3DGS 不同，这里没有 front-to-back alpha compositing，也不把 kernels splat 到 screen：颜色只在 ray 与 mesh 的交点处动态查询。

消融中移除 colour-formation KNN 几乎不改变精度（Table 4：完整模型 PSNR 45.05，移除后 45.04），说明它主要是工程级局部筛选，而非质量来源。

### 5. 如何让每个 kernel 拥有连续可学习的各向异性

每个 $(\eta,	heta)$ 都直接 eigendecompose ALBO 不现实。作者离线构造 $7$ 个 angle × $7$ 个 anisotropy 的 half-polar grid：anisotropy 先映射到 $s=\ln(1+\eta)$，再在相邻四个节点间对 eigenvalues/eigenvectors 做 bilinear interpolation（Eq. 8）。

难点在于 eigenvectors 存在 permutation、子空间 rotation 与 sign ambiguity，不能直接插值。每个 grid node 先经过：

1. mass-weighted cross-correlation + Hungarian assignment 解决 eigenmode permutation；
2. mass-weighted Orthogonal Procrustes/SVD 对齐旋转；
3. diagonal sign matrix 修正符号翻转。

随后，顶点上的谱量通过 barycentric interpolation 在任意 face interior 连续求值。该链条将“离散 mesh eigensystem”转化为“对 source position、query position、angle 和 anisotropy 均可微/可插值”的核。

**个人分析**：这是论文技术上最关键也最脆弱的部分。它不是解析地求解连续 ALBO，而是“参数网格插值 + 空间重心插值”的双重近似；效果依赖 eigenbasis 对齐稳定性、grid resolution 和 $K=256$ 的谱截断。正文没有给出角度/各向异性网格分辨率或 $K$ 的系统误差曲线。

### 6. 黎曼位置优化：梯度、动量与更新都留在曲面上

对 source position 的普通 3D gradient 会指向 mesh 外。HKTex 将 $\nabla_{\boldsymbol p^\star}\mathcal L$ 投影到 tangent plane $\mathcal T_{\boldsymbol p^\star}\mathcal M$ 得到速度，再用 exponential map 沿 straightest geodesic 更新：

$$
\boldsymbol p_{\mathrm{new}}^\star
=\operatorname{Exp}(\boldsymbol p^\star,\mathbf v^\star).
$$

若使用 momentum，还需将旧 tangent space 中的动量 parallel transport 到新位置。实现依赖 DiGeo 的 CUDA-parallel differentiable straightest geodesics。相比“优化后投影回 mesh”，这种更新显式保留表面方向和跨三角形传播的几何一致性。

### 7. 流形感知 density control

#### Pruning

在窗口 $\Delta_{\mathrm{prune}}$ 内统计：

- hit count $\nu(\boldsymbol\kappa_s)$：kernel 被选进局部 partition 的频率；
- energy $\omega(\boldsymbol\kappa_s)$：累计 filtered weight $\alpha_s$。

命中率相对过低或能量绝对过弱的 kernel 被删去，以减少无效查询和序列化参数。

#### Error-based densification

把点误差

$$
e(\boldsymbol p)=\|C(\boldsymbol p)-C_{\mathrm{GT}}(\boldsymbol p)\|_1
$$

按归一化 kernel contribution 分摊成 per-kernel score $E(\boldsymbol\kappa_s)$。高误差 kernel 根据 $1-\tau_s$ 判断大小：

- 小 kernel：原地 clone，让优化器自行分离；
- 大 kernel：沿其 manifold principal axis split 成两个更小 kernel。

split 使用

$$
\boldsymbol p_{\mathrm{new}}^{\star(\pm)}
=\operatorname{Exp}\left(
\boldsymbol p_{\mathrm{old}}^\star,
\pm\hat{\mathbf d}^\star(1-\tau_{\mathrm{old}})r_{\mathrm{base}}
\right),
$$

并将新阈值设为

$$
\tau_{\mathrm{new}}=1-\frac{1-\tau_{\mathrm{old}}}{1.6}.
$$

因此位置不会脱离表面，子核沿父核长轴分开且 footprint 缩小；新参数的 optimizer states 归零，避免继承触发 split 的极端梯度。

Table 4 表明真正重要的是**误差增密**而不是 pruning：禁用增密后 PSNR 从 45.05 降到 43.05、kernel 从约 4811 降到 995；仅禁用 pruning 则几乎完全不变（45.06、4810）。

### 8. 两种监督路径

#### A. 压缩/拟合既有 UV texture

训练时在 mesh faces 上采样连续点，查询原 UV texture 得到 $C_{\mathrm{GT}}(\boldsymbol p)$，以 MSE 优化 HKTex。UV 仅作为训练监督，最终表示不再需要 UV atlas。补充材料还使用 error EMA 驱动 importance sampling，把更多 batch 分配给高误差/高频区域。

#### B. 从多视图图像逆渲染

将 HKTex 包装成 Mitsuba 3 的 custom differentiable texture，并挂到 Principled BSDF 的 albedo。随机相机产生 rays，保留命中 mesh 的交点；每次用 1024 rays、每 ray 8 gradient spp，通过 Dr.Jit ↔ PyTorch 和 path-replay backpropagation 反传。报告设置共 3840 次 inner mini-batch updates，gamma-space L1 loss 为：

$$
\mathcal L_{\mathrm{ray}}
=\frac{1}{B}\sum_{i=1}^{B}
\|\tilde{\mathbf c}_i-\tilde{\mathbf c}'_i\|_1,
\qquad B=1024.
$$

**训练与推理区别**：UV importance sampling、photometric loss、gradient ray samples、黎曼更新与 density control 仅训练时使用；推理仍需对每个 surface query 做 biharmonic KNN、局部 heat-kernel evaluation 和 colour blending，但 KNN database 与 source self-kernel 可一次预计算。

## 实验关键数据

### 实验设置

- **数据**：从 Objaverse 过滤约 3000 个 mesh；要求有 LVIS label、有效纹理、至少一个 like/view，且不是 point cloud/animated model。进一步要求单连通分量、manifold、无复杂内部结构、最多 60k vertices、LBO eigendecomposition 成功。
- **UV fitting**：随机选 313 个 mesh；每个对象渲染 5 个视角做指标。
- **Multi-view**：162 个 mesh 的 synthetic rendered observations，已知 mesh/camera，且只恢复 albedo；不是带未知光照、几何和材质的真实照片。
- **Ablation**：92 个 Objaverse meshes。
- **指标**：PSNR/SSIM/MS-SSIM 越高越好；LPIPS/MSE、render time、storage 越低越好。Storage 统计表示所需 intrinsic parameters、network weights 和 UV coordinates/topological overhead，以同一格式并统一 zip，不用 method-specific quantization。
- **主要基线**：LR/HR GT UV texture、GT/HR vertex texture、Fourier positional-encoding MLP、InstantNGP、Intrinsic Neural Fields、ImageGS；多视图还包括固定 GT mesh/environment、只预测 albedo 的 NVDiffRec* adaptation。

| GT VTex | 37.9 | 4.0 | 96.8 | 96.1 | 0.94 | **25.4** | **17.3** |
| HR GT VTex | 45.3 | **1.1** | 98.8 | 99.4 | **0.08** | 50.3 | 179.6 |
| MLP Pos. Enc. | 42.9 | 2.3 | 98.2 | 99.0 | 0.15 | 90.9 | 551.3 |
| InstantNGP | 41.3 | 3.2 | 97.5 | 98.2 | 0.26 | 90.8 | 473.2 |
| Intrinsic Neural Fields | 42.5 | 2.7 | 98.0 | 98.8 | 0.19 | 91.4 | 928.2 |
| ImageGS | 44.6 | 2.9 | 97.3 | 95.9 | 3.65 | NA | 115.4 |
| **HKTex（约 4.8k kernels）** | 44.8 | 1.3 | **98.9** | **99.5** | **0.08** | 784.7 | 96.6 |

关键解读：

1. **质量/体积成立，但不是所有指标第一**：HKTex 的 SSIM、MS-SSIM 最好，MSE 与 HR VTex 并列最好，LPIPS 次于 HR VTex；PSNR 44.8 dB 低于 LR UV 的 48.4 与 HR VTex 的 45.3。
2. **相对 neural fields 的压缩很强**：相较 MLP/InstantNGP/INF，平均 storage 从 473–928 KB 降到 96.6 KB，同时图像指标整体更好。
3. **相对低分辨率 UV 的优势并非全面**：HKTex 少约 16.6% storage（96.6 vs. 115.8 KB），结构/感知指标更好，但 PSNR 低 3.6 dB；不能简化成“全面胜过 UV texture”。
4. **速度是明显短板**：784.7 ms 约为 MLP/InstantNGP 的 8.6 倍、HR VTex 的 15.6 倍、GT VTex 的 30.9 倍。标题里的“do not splat”也意味着它不享受 screen-space splatting 的直接高速 rasterization。
5. **GT VTex 只有 17.3 KB**，但质量明显差；HR VTex 质量略优/相当，却需要 179.6 KB。HKTex 的价值是更好的 rate–distortion，而不是绝对最小文件。

| **HKTex（约 3.8k kernels）** | **37.61** | **2.1** | **98.3** | **98.6** | **0.30** | 1.20 | **78.73** |

- HKTex 在所有质量指标和 storage 上领先表中基线；对 HR VTex 的 PSNR 是 +0.45 dB，LPIPS 从 0.031 降至 0.021，storage 只少约 2.9%。
- 其优势相对 MLP/NVDiffRec* 更明显，但这两者为匹配容量做了 architecture grid search，平均 storage 仍比 HKTex 大 6–8 倍，说明“严格 matched budget”实际上并未完全实现。
- render time 是 HR VTex 的约 2.07 倍。作者认为多 bounce ray tracing 占主导后，kernel overhead 被部分摊薄，但仍未消失。
- **证据不能支持真实照片场景**：训练图像由已知 GT UV albedo 合成；geometry、camera、environment 均不需要联合估计。补充材料也明确指出，若直接换成真实照片，当前 albedo-only 模型会把阴影、光照和 view-dependent reflection 烘焙进 diffuse colour。

**消融所能说明与不能说明的内容**：

- 最清晰的因果证据是 densification 和 biharmonic weighting；去掉后多个指标同步下降。
- pruning 与 colour KNN 在该设置里不是 accuracy-critical component。保留它们更可能是为了减少失活 kernel 或局部计算，但 Table 4 没报告各变体 render time，无法验证速度收益。
- “No importance sampling”平均 PSNR 略高于 Full，不应宣称 importance sampling 全面提升质量；其主要证据是 MSE 从 $0.058\pm0.082$ 恶化到 $0.691\pm6.148$，即减少灾难性长尾失败。
- 没有 ALBO interpolation、Riemannian optimizer、谱维度、grid resolution、$K_s/K_c$ 的单独消融，核心几何设计的必要性仍未被完整拆开验证。

### 计算、存储与预计算成本

- isotropic LBO 用 64 eigenmodes 构造 biharmonic embedding；每个 7×7 ALBO 节点使用 256 eigenmodes。
- 每 mesh 的 49 组 ALBO eigenproperties 平均约 **370 MB**；作者认为它们是 mesh 可确定性重算的辅助量，因此不计入最终 texture storage。
- 预计算平均 **97.8 ± 286.9 s/mesh**，也未计入论文 timing；其中 Hungarian 对齐 49 组 eigenvectors 仅 0.05 ± 0.03 s，主要成本是 eigendecomposition。
- 补充材料称测试 mesh 平均约 $9.6\pm19$k vertices，HKTex 约 $4.3\pm0.6$k kernels；49.8% faces 没有 kernel center，说明 kernels 确实按纹理内容而非 mesh tessellation 分配。
- 论文用“两三角形矩形拟合图像”展示不被 vertex count 限制，但该特例只有 $K=3$ eigenmodes，并额外把 $\tilde h_t$ 提升为 $(\tilde h_t)^{30}$；它证明表达不必一 kernel/vertex，却不是复杂曲面上的高分辨率 scalability 证据。

**复现风险：论文文本与公开配置存在值得核查的口径差异。**

1. Sec. 5.2 把 threshold 初始化写为 UV 0.9–1.0、multi-view 0.7–1.0；补充初始化段又写 $\tau_{\min}=0.7$（UV）和 0.9（multi-view）；Table 3 与当前 YAML 则分别给 **0.3（UV）/0.7（multi-view）**。需要进一步读初始化代码确认 `init_min_threshold` 的准确语义。
2. 补充材料写 UV importance pool 为 **10M points**，公开 `texture_hktex_knn.yaml` 当前设为 **1,000,000**。这可能是代码更新、笔误或复现实验与默认配置不同，不能默认二者等价。

## 关键发现

1. **内蕴 kernel representation 有效**：在同等或更小最终 storage 下，HKTex 相比 neural fields、ImageGS 和 native vertex colour 获得更好的结构与感知质量（Tables 1–2）。
2. **局部支持是系统成立的关键**：biharmonic attenuation 同时缓解谱截断伪影，并允许把全连接 kernel evaluation 降为固定邻域查询；消融支持其质量作用。
3. **容量应按 signal complexity 而非 mesh tessellation 分配**：误差驱动增密显著提升质量，kernel centers 高度不均匀分布于 faces；这解释了它为何比 vertex colour 更适合纹理高频区域。
4. **“小纹理文件”不等于“小工作集/快渲染”**：96.6 KB 是可学习 kernel parameters 的最终序列化体积，不包含约 370 MB 的可重算谱数据；直接纹理拟合的 render latency 也显著高于所有可比较基线。
5. **多视图结论目前只覆盖受控 synthetic albedo recovery**，尚未证明真实照片、未知光照、复杂材质或联合 geometry/material estimation。

## 亮点与洞察

### 论文亮点

- **概念统一**：把 Euclidean Gaussian ↔ manifold heat kernel 的数学对应用于 texture primitives，不是给 3D Gaussian 再加 surface regularization，而是从表示层面消除 ambient-space mismatch。
- **全链条内蕴化**：primitive shape、continuous query、position update、momentum transport、split displacement 与 neighborhood search 都围绕 mesh geometry 设计，而非只在初始化时贴合表面。
- **几何与工程结合紧密**：谱基对齐/插值、biharmonic FAISS KNN、Triton、DiGeo、Mitsuba/Dr.Jit 共同把理论表示做成可训练系统。
- **实验报告较透明**：正文同时给 quality、render time 与 storage；补充材料披露 370 MB cache、97.8 s precomputation、synthetic multi-view 的现实边界和直接编辑困难。
- **代码公开且配置细致**：依赖、两条训练路径、ablation configs 和主要超参数均可查，尽管仍存在文本/配置口径不一致。

### 我的洞察

1. **HKTex 更像“曲面 vector graphics”而非“新式 bitmap compression”**：kernel 位置、方向、各向异性和边界锐度形成内容自适应的曲面 primitives；最终 colour 是 partition-of-unity field。其价值可能更接近 diffusion curves / radial basis functions on manifolds，而不是替代 GPU texture unit 的即时方案。
2. **方法把存储从 asset-specific signal 转移到 geometry-derived operator**：kernel file 很小，是因为大体积 spectral basis 可由 mesh 重算。若同一个 mesh 有许多材质/纹理变体，这个固定成本可摊销；若移动端只加载一次单个 asset，370 MB 工作集会削弱“memory footprint”叙事。
3. **压缩率来自强先验，而不只是 kernel 形式**：已知高质量 manifold mesh、固定 topology、可成功 eigendecompose 的 LBO，以及 albedo-only 都显著缩小了问题。与同时重建 geometry/radiance 的 3DGS 并非同一任务。
4. **误差增密是可迁移的容量分配原则**：任何 surface field（roughness、metallic、semantic label、displacement）都可按 residual 而不是 tessellation density 分配局部 basis；这可能比“热核”本身更容易迁移到现有系统。
5. **速度瓶颈具有结构性**：即便 KNN 降到 $K_s=50$，每 query 还需参数谱插值、双位置 barycentric gathering、256-mode heat sum 与 colour aggregation。只做 kernel fusion 不一定能追平硬件 UV sampling，需要 baking/cache/LOD 或专用 basis compression。

## 局限与展望

### 作者明确承认的局限

- 当前只建模 **albedo**；roughness、specular/metallic、normal 等 spatially varying BSDF parameters 留待未来扩展（Sec. 6）。
- 直接编辑不自然。补充材料建议把局部 bake 成 dense point cloud、绘制后再短暂优化；这明显不如成熟 UV authoring pipeline 直接。
- 谱预计算约 370 MB/mesh、97.8 s，当前为 CPU sequential overhead；作者建议未来 GPU parallel eigendecomposition/recomputation。
- 真实照片会把 illumination、shadow 和 view-dependent effects bake 到 diffuse albedo，完整 PBR inverse rendering 需要联合材质分解。

### 独立分析

1. **网格适用范围窄于“arbitrary triangular meshes”的宣传语**：实际数据过滤掉 disconnected、non-manifold、复杂内部结构、>60k vertices 和 eigendecomposition failure。更准确的结论是“适用于通过严格几何筛选、可稳定谱分解的 manifold meshes”。
2. **存储统计公平性需要两个口径**：论文排除可确定重算的 spectral cache 在压缩论文中有合理性，但部署还应报告 cold-start（mesh + texture + temporary eigenbasis）、warm runtime working set 与 amortized multi-texture cost。
3. **缺少 end-to-end wall-clock**：没有完整训练时间、峰值 GPU/CPU memory、预计算随 $N$ 的缩放曲线，也未测试主流实时 texture sampling 场景。Table 1 已显示 784.7 ms，当前不适合直接声称游戏/VR 落地。
4. **基线预算匹配不完全**：neural baselines 的平均 storage 显著大于 HKTex；LR UV 与 ImageGS 又受每顶点 UV overhead 主导。建议同时报告固定 25/50/100/200 KB 的 rate–distortion curves，而不是每方法单个工作点。
5. **关键近似未充分消融**：需分别测试 $K=64/128/256/512$、ALBO grid 3×3/7×7/更密、exact vs interpolated ALBO、小/大 $K_s$，并报告 angular/anisotropy interpolation error 与质量/时间关系。
6. **多视图任务太受控**：应增加真实 multi-view dataset、未知 exposure/illumination、遮挡与不准 camera/geometry，至少联合 albedo + roughness + metallic，并与成熟 inverse-rendering texture parameterization 比较。
7. **统计波动很大**：多项结果标准差较高，例如 ALBO precompute $97.8\pm286.9$s、storage baselines 也呈长尾。论文给均值但没有 median/percentiles 或按 mesh complexity 分组，部署风险难判断。
8. **谱的 topology/global dependency 带来编辑问题**：几何或 topology 一旦改变，eigenbasis 和 biharmonic embedding 可能整体变化；论文没有测试 geometry deformation、remeshing、LOD 切换与 kernel transfer。

### 建议的后续实验

- 在同一批 meshes 上画 **quality–serialized-size–warm-memory–latency 四维 Pareto curves**，并将 370 MB spectral data 分别按 cache、recompute、compressed basis 三种部署模式计入。
- 对 non-manifold、多 component、100k–1M vertices、不同 tessellation/remeshing 的 mesh 做鲁棒性测试，并测 kernel transfer consistency。
- 在 DTU/real object captures 或自建 calibrated real dataset 上联合优化 albedo、roughness、metallic、lighting，报告 relighting 而不只是 novel-view image similarity。
- 开发 mip/LOD：远距离将邻近 heat kernels merge，近距离才查询完整 $K_s$，验证是否可把 784.7 ms 降到可交互范围。
- 对论文/配置不一致的 threshold 和 importance-pool 设定做复现实验，发布确切 commit、评测 object IDs 与一键脚本。

## 与相关工作的对比

| 方法 | 表示域与机制 | 是否依赖 UV | 与 mesh/tessellation 的关系 | 查询/渲染特性 | 论文中体现的结果 |
| --- | --- | --- | --- | --- | --- |
| LR/HR UV Texture | 2D bitmap + surface parameterization | 是 | 需 UV coords，seam 可复制 vertices | 硬件采样快、编辑成熟 | PSNR 高；UV/topology overhead 在高顶点 mesh 上显著 |
| Vertex Texture | 每顶点颜色 + 面内插值 | 否 | 容量强绑定 vertex placement/density | 极快、简单 | native VTex 小但细节差；subdivision 后质量高但存储增大 |
| MLP / InstantNGP | ambient 3D coordinate → colour | 否 | 不直接受 UV 限制，但不是内蕴 surface representation | 每点网络/hash 查询 | 约 473–602 KB 以上，质量低于 HKTex |
| Intrinsic Neural Fields | LBO eigenfunction coordinates + MLP | 否 | 使用内蕴谱，但仍依赖 MLP 全局函数 | 每点 MLP 求值 | UV fitting 42.5 dB、928 KB、91.4 ms |

| **HKTex** | manifold 上各向异性 heat kernels + Riemannian optimization | 最终否 | 连续查询，不绑定 vertex colour；依赖稳定 mesh spectrum | ray intersection 动态查询，当前较慢 | 96.6 KB、44.8 dB、SSIM/MS-SSIM 最优 |

最接近的思想脉络包括：

- **Intrinsic Neural Fields**：同样用 LBO eigenfunctions 构造内蕴坐标，但 HKTex 改为局部显式 kernels，并允许位置/形状/密度自适应。
- **UV-free Texture Generation with Denoising and Geodesic Heat Diffusion**：同一团队此前已用 geodesic heat diffusion 做 UV-free texture generation；HKTex 将热扩散进一步变成可学习的显式表示原语。
- **3D Gaussian Splatting / ImageGS**：提供局部 Gaussian primitive 与 adaptive density control 的设计灵感；HKTex 保留“局部可增密”思想，但不进行 splatting。
- **DiGeo / differentiable straightest geodesics**：为 kernel source 的 exponential map 与 parallel transport 提供可训练 GPU 基础设施，是位置优化可行的关键依赖。

## 启发与关联

- **对 3DGS/mesh hybrid research**：可把 surface-constrained attributes 从“ambient Gaussian + regularization”改写为真正的 manifold basis；例如 mesh 上的 residual appearance、semantic field 或 deformation weight 可以采用 intrinsic kernels。
- **对 inverse rendering**：将每个 kernel 的 $\mathbf c$ 扩为 albedo/roughness/metallic/normal residual，并共享位置、方向和 footprint，可能形成结构化 SVBRDF primitives。**这是可行性假设，论文尚未验证。**
- **对 compression**：把 geometry-derived dictionary 与 signal coefficients 分开计价；当多个 texture variants、animation frames 或 material channels 共享同一 mesh spectrum 时，预计算可摊销，HKTex 的经济性可能比单纹理实验更强。
- **对自适应采样**：error-based densification + error-EMA importance sampling 可迁移到 neural texture、surface neural field 与 point-based attribute fitting，尤其适合纹理频率与 geometry tessellation 不匹配的区域。
- **对编辑工具**：可以研究 kernel-level brush：画笔不修改 UV pixel，而是直接选择 biharmonic neighborhood 内 kernels，更新 colour/threshold/orientation；但需解决参数耦合和局部编辑引起的非局部谱响应。

## 阅读结论

- **最值得记住的点**：Gaussian 在曲面上的真正对应物不是“压扁并贴住的 3D 椭球”，而是随 geodesic 弯曲的 heat kernel；表示、优化、增密和查询都应遵守同一内蕴几何。
- **最需要怀疑的点**：“显著降低 memory footprint”只在最终 kernel parameter 文件口径下成立；约 370 MB/mesh 的谱数据、97.8 s 预计算与 784.7 ms render 必须纳入实际系统评估。
- **最值得复现或继续验证的点**：先复现 Table 1 与 Table 4，核对 threshold/importance-pool 配置差异，再系统扫描 eigenmodes、ALBO grid 和 KNN 大小，得到完整质量–存储–内存–速度 Pareto 曲线。
